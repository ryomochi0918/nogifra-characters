# スキルフローチャート図鑑

一覧画面からキャラクターを選ぶと、乃木フラキャラクターのスキルのフローチャートを見られるサイトです。

## ローカルで確認する

`fetch()` でJSONと.mmdファイルを読み込む都合上、`index.html` を直接ダブルクリックでは動かないため(ブラウザのCORS制限)、以下のように簡易サーバーを立てて確認してください。

```bash
cd nogifra-characters
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 新しいキャラクターを追加する

> [!CAUTION]
> 具体的な追加手順は公開していないので、要望がある場合は管理者に連絡ください。

- データフォーマットは以下に従います
  - ref: `./data/characters.json`

```json
{
  "name": "キャラ名",
  "nameReading": "きゃらめいのひらがな(50音順ソート用、必須)",
  "costume": "衣装名やカードの通称",
  "costumeReading": "いしょうめいのひらがな(同キャラ内でのソート用、必須)",
  "title": "スキル名やカードの通称(表示用)",
  "tier": "LR",
  "addedDate": "2026-08-01",
  "generation": "◯期",
  "attribute": "努力/感謝/笑顔のいずれか",
  "skills": [
    { "type": "active", "label": "スキル1: ○○", "file": "data/xxx_skill1.mmd", "text": "原文全文(任意)" }
  ],
  "passive": [
    { "condition": "パッシブ1", "effect": ["文の切れ目で区切った箇条書き1", "箇条書き2", "..."] }
  ]
}
```

- `nameReading` / `costumeReading` は検索対象ではなく**並び順専用**のひらがなです。
- `passive[].effect` は文字列ではなく**配列**です。**文の切れ目で区切ります**(読点での機械的な分割は禁止。文の途中で切れて意味が通らなくなるため)。分割ルールと一括整形スクリプトは `docs/characters-schema.md` を参照してください。
- `※`で始まる項目(バフ状態の定義、アドバンス/アンコールスキルの本文)は、ビューアが**本文と分けて表示します**。`※◯◯:` の見出し部分は自動でラベルとして切り出され、`[①][②]` は段落として改行されます。データ側は原文どおり1項目のままにしておけば構いません。
- `attribute` を活用すると、「11thバスラ〜◯期生ライブ〜」「真夏の全国ツアー2024・白衣装」のような一部の衣装テンプレートは「同じ期・同じ属性」のキャラ同士でスキル内容が完全一致するため、既存キャラのmmd/textをコピーして名前だけ差し替える高速化ができます(ただし属性が違えば内容も別なので、コピー前に必ず属性が一致するか確認すること)。

## 検索機能

ページ上部の検索欄には複数の絞り込み条件があります。

- 絞り込み条件
  - **検索窓**: 検索形式は部分一致検索(`LIKE '%...%'`相当)で、正規表現にも対応しています
    - 検索内容は、キャラ名・衣装名・期(「6期」など。新4期生・春組/夏組といった括弧書きは対象外)・スキル名・スキル内容です
    - ※不正な正規表現(入力途中など)の場合は、正規表現ではなく通常の部分一致検索にフォールバックします
  - **メンバー選択**: 任意のメンバーで検索します
  - **期生選択**: 任意の期のメンバーで検索します
  - **属性選択**: 努力・感謝・笑顔のいずれかから検索します
  - **卒業済みメンバーも表示**: チェックの状態はブラウザ(localStorage)に保存され、次回も引き継がれます

## 比較モード

検索欄の「比較モード」を押すと、カードをタップしても詳細ビューアは開かず、比較対象として選ぶ状態になります(右上にチェックが付く)。2〜3体選んで画面下の「比較する」を押すと、比較ビューアが開きます。キャラの詳細ビューアの右上(閉じるボタンの隣)にある「⇄ 比較」を押すと、そのキャラを選んだ状態で比較モードに入ります。

- タブ(スキル1/スキル2/パッシブ)は全員で共通で、切り替えると全員分が同じタブの内容に切り替わります
- 各キャラのフローチャートの上にズーム( −/＋/リセット )があり、キャラごとに別々に拡大縮小できます(50%〜400%)。タブを切り替えると100%に戻ります
- 幅900px超(PC)では横に並べます
- それより狭い画面(スマホ・タブレット縦)では、1列を表示幅の88%にして横スクロールで切り替えます。スワイプすると1体ずつピタッと止まり、右端に次のキャラが少し見えます。上部の名前ボタンで列を移動でき、今見ている列のボタンが光ります。タブを切り替えても、見ていたキャラの位置は保たれます
- 画面下のバーの「選択中 N/3」を押すと、選択中キャラの一覧が開きます。検索・絞り込みでカードが表示されていないキャラも、ここから1体ずつ解除できます
  - 解除したキャラは、一覧を開いている間は薄く(取り消し線付きで)残り、「戻す」で選び直せます。一覧を閉じると消えます
  - 一覧の外を押すか`Esc`キーで閉じます
- 「終了」で選択を全部消して比較モードを終えます

## 表示設定の保存

ライト/ダークモードと「卒業済みメンバーも表示」はlocalStorageに保存します(キー: `nogifra-theme` / `nogifra-show-graduated`)。

検索窓の文字・キャラ/期/属性の絞り込み・比較モードの選択状態は、sessionStorageに保存します(キー: `nogifra-search-state`)。再読み込みしても残り、タブを閉じると消えます。テーマは`<head>`内の小さなスクリプトで描画前に反映し、読み込み時のちらつきを防いでいます。localStorageが使えない環境(プライベートモード等)では保存されないだけで、表示は通常どおり動きます。

## フローチャートビューアの操作

キャラクターカードをクリックすると開くビューア内で、フローチャートに対して以下の操作ができます。

- **ズーム( −/＋/リセット )**: 表示中のSVGを50%〜400%の範囲で拡大縮小します
- **拡大表示( ↕ )**: フローチャート表示エリアの高さをその場で1.5倍に広げます。収まりきらない分は下にスクロールして見られます。もう一度押すか`Esc`キーで元のサイズに戻ります
- **凡例( ? )**: ノードの色分け(開始・終了/条件分岐/条件成立時の効果付与/実際のアピール・攻撃)を表示します。外側クリックまたは`Esc`キーで閉じます
- **原文を見る**: スキルの原文全文を折りたたみ表示します。タブ切り替え・キャラ選択のたびに閉じた状態から始まります

「パッシブ」タブでは、`※`で始まる注記(バフ状態の定義、アドバンス/アンコールスキルの本文)を通常の効果とは別枠で表示します。`※◯◯:` の見出しはラベルとして色分けされ、アドバンス/アンコールスキルの `[①][②][③]` は段落ごとに改行されます。

表示エリアが狭いとき(スマホ、比較モードの各列など)は、パッシブ表を2カラムから縦積みに切り替えます(画面幅ではなく表示エリアの幅で判定するコンテナクエリ)。パッシブ1/2/3はすべて同じ形で、「パッシブN」が見出し行になり効果内容が全幅で表示されます。

## 並び順

キャラ名の50音順→同キャラ内は衣装名の50音順です(`nameReading` / `costumeReading` を使用)。

## 構成

```
./
├── index.html                              # カード一覧+ビューアのHTML(<head>にOGP/twitter:cardのメタタグを含む)
├── css/
│   └── styles.css                         # スタイル(ライト/ダークモード切り替え対応)
├── js/
│   └── index.js                           # 検索・絞り込み・ビューア等のロジック
├── assets/
│   ├── logo.svg                           # サイトロゴ(favicon兼ヘッダー表示用)
│   └── ogp.png                            # SNS共有カード用画像(1200x630)
├── data/
│   ├── characters.json                    # キャラ一覧のメタデータ
│   ├── nogizaka46_members_reading.json    # 現役メンバー等の読み仮名・期データ
│   ├── _templates/                        # 期・属性で内容が共通する衣装テンプレート(非公開衣装追加フロー用)
│   └── {キャラslug}/                      # キャラごとのMermaidフローチャート(例: ioki_mao/, ikeda_teresa/)
│       └── *.mmd
└── README.md
```

mermaid.jsはcdnjs経由でCDN読み込みしているため、リポジトリ側でのビルドや依存関係管理は不要です。

`index.html` では `css/styles.css?v=YYYYMMDD` / `js/index.js?v=YYYYMMDD` のように版番号を付けて読み込んでいます。**CSS・JSを変更したら、この版番号を変更日に書き換えてください**(同じ日に2回目以降の変更をするときは`-2`・`-3`と枝番を付ける)。書き換えないと、ブラウザに残った古いCSS・JSと新しいHTMLの組み合わせで読み込まれ、ページが動かなくなることがあります(GitHub Pagesはファイルを10分ほどキャッシュさせるため)。

## SNS共有カード(OGP)

`index.html` の `<head>` に OGP (`og:*`) と `twitter:card` (`summary_large_image`) のメタタグを置いています。X・Discord・LINE などにURLを貼ると、`assets/ogp.png` を使った横長カードで表示されます。

- 画像は 1200x630。`css/styles.css` のダークテーマの変数(`--bg-0` / `--spotlight` / `--attr-*`)と同じ配色で作成しています。
- **画像にもメタタグの説明文にも、キャラ数や件数といった変動する数字は入れていません。**新キャラが追加されるたびに作り直しになるためです。数字を足したくなったときは、この方針ごと見直してください。
- X はカードを一定期間キャッシュします。メタタグを変更したら、GitHub Pages への反映を確認してから共有し直してください。

## 読み仮名の参考データ

`data/nogizaka46_members_reading.json` に、現役メンバー(+LR登場以降に卒業したメンバー)の名前の読み仮名(`nameReading`用)をまとめてあります。
